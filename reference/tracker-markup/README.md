# Tracker markup

This directory holds reference material for preparing text in trackers with different markup behavior.

- [Bugzilla comment syntax](./bugzilla-comment-syntax.md) explains that Bugzilla comments are plain text, so conventions remain legible as literal monospace text.
- [Jira wiki markup](./jira-wiki-markup.md) explains that Jira renders wiki markup with headings and emphasis but does not render Markdown.

Both documents record upstream facts with dated citations under [`guides:citations-live-in-the-reference-zone`](../../_docs/specs/SPEC-guides.md).
