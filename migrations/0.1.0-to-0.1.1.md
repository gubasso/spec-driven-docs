# Migration from 0.1.0 to 0.1.1

## Applicability

Apply this guide to instances whose manifest reports `0.1.0`.

## Preconditions

1. Run offline verification.

   ```bash
   .spec-driven-docs/verify.sh --target /path/to/your-project --offline
   ```

## Managed changes

- No projected file changes. The correction is to `.hooks/version-source-of-truth.sh`, which the
  canon runs on itself and does not project into an instance.

## Living rule-ID changes

- None.

## Local integration action

1. None. Update `canon_version` and `canon_ref` in the manifest to the new release.

## Verification

1. Run the project gate and offline verifier.

   ```bash
   .spec-driven-docs/verify.sh --target /path/to/your-project --offline
   ```

## Rollback

1. Restore the project snapshot taken before the upgrade.
